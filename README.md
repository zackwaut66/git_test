# Ashen Marches — Prototype 0.1

Persistent mobile-first 2D gothic post-apocalyptic strategy RPG/MMO-lite prototype.

## Current playable loop

Enclave → Ashen Marches expedition → automatic formation combat with Resolve abilities → loot → equipment/set bonuses or salvage → Hunter XP/levels → Enclave upgrades → deeper Marches → Penitent Warden boss.

## Implemented

- Persistent browser save via localStorage
- Mobile-first interface
- Enclave hub and four upgradeable facilities
- Three-Hunter formation
- Hunter XP and leveling
- Four-node exploration map with progressive fog reveal
- Automatic combat
- Focus Strike and Field Treatment tactical abilities
- Retreat/failure/victory states
- Penitent Warden boss encounter
- Common, uncommon, rare and relic loot
- Gear affixes
- Ashen Pilgrim equipment set bonus
- Equip/remove/salvage loop
- Coin, Iron and Salvage economy
- Forge/Infirmary upgrade effects
- Gothic visual interface
